# Les anges dans nos campagnes
*Les anges dans nos campagnes* is a popular French *cantique de Noël* (Christmas carol) from the early 19th century. 

It is known in English as [Angels We Have Heard on High](https://en.wikipedia.org/wiki/Angels_We_Have_Heard_on_High).
