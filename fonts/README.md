Vendored fonts for reproducible PDF builds.

- `HaranoAjiMincho-Regular.otf`: Harano Aji Mincho, used for Japanese vertical text.
- `HaranoAjiMincho-Bold.otf`: Harano Aji Mincho Bold, used for Japanese music titles.
